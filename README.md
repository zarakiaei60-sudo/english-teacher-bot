# 🗣 English Teacher Bot

A friendly Persian-first Telegram bot for learning everyday English conversation.
Built for absolute beginners: every question comes with a Persian translation,
pronunciation guide, and sample answers.

## Features
- 🐣 Conversation scenarios (first steps, introductions, café, shopping)
- 🎯 Sentence drills with fuzzy answer checking + score & streak
- 📚 Phrasebook with audio pronunciation (🎧)
- ✏️ Gentle correction of common beginner mistakes
- 🔒 Admin-only commands (/stats) — everyone else can just learn!

## Run it yourself
1. Create a bot with @BotFather and put the token in repo Secrets as `BOT_TOKEN`
2. Put your Telegram numeric ID in Secrets as `ADMIN_ID`
3. The scheduled Action keeps the bot alive 24/7 (free on public repos)
